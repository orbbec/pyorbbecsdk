2.1. 虚拟环境安装指南

建议在虚拟环境中安装 pyorbbecsdk

现代操作系统（尤其是 macOS 和较新的 Linux 发行版）越来越严格地限制系统 Python 环境的修改。使用虚拟环境可以：

  • 避免权限错误和系统保护机制的限制

  • 防止不同项目之间的软件包冲突

  • 创建可复现的依赖环境

  • 同时支持多个 Python 版本

2.1.1. 📋 目录

  1. 快速入门

  2. 使用 venv（适合初学者）

  3. 使用 pyenv（管理多个 Python 版本）

  5. 各平台注意事项

2.1.3. 快速入门

以下安装命令包含 Wrapper 2.1.4 及更新版本的可选 [examples] 依赖。如果应用仅需要核心功能，请改用 "pyorbbecsdk2"。请为完整参数加引号，避免 zsh 等 shell 展开方括号。

2.1.3.1. Linux / macOS (venv)

# Create virtual environment
python3 -m venv orbbec_env

# Activate environment
source orbbec_env/bin/activate

# Install SDK
pip install --upgrade "pyorbbecsdk2[examples]"

# Verify installation
pip show pyorbbecsdk2 | grep Version

2.1.3.2. Windows (venv)

# Create virtual environment
python -m venv orbbec_env

# Activate environment (PowerShell)
.\orbbec_env\Scripts\Activate.ps1

# Install SDK
pip install --upgrade "pyorbbecsdk2[examples]"

# Verify installation
pip show pyorbbecsdk2 | findstr Version

2.1.4. 1. 使用 venv（适合初学者）

venv 是 Python 标准库自带的虚拟环境工具，无需额外安装。

2.1.4.1. 1.1 检查 Python 版本

确保已安装受支持的 Python 版本（3.8 至 3.14）：

Linux/macOS:

python3 --version

Windows:

python --version

2.1.4.2. 1.2 创建虚拟环境

在项目目录中创建虚拟环境：

所有平台：

# Linux/macOS/Windows universal
python3 -m venv orbbec_env

# Windows if python3 command is not available, use:
python -m venv orbbec_env

命名建议：使用 orbbec_env 或 .venv 作为环境名

2.1.4.3. 1.3 激活虚拟环境

Linux/macOS:

source orbbec_env/bin/activate

Windows (CMD):

orbbec_env\Scripts\activate.bat

Windows (PowerShell):

.\orbbec_env\Scripts\Activate.ps1

激活后，命令提示符会显示环境名：

(orbbec_env) user@computer:~$

2.1.4.4. 1.4 安装 pyorbbecsdk2

在已激活的虚拟环境中安装：

pip install --upgrade "pyorbbecsdk2[examples]"

2.1.4.5. 1.5 验证安装

pip show pyorbbecsdk2

预期输出：

Name: pyorbbecsdk2
Version: 2.0.16
...

2.1.4.6. 1.6 运行示例

# Test import
python -c "import pyorbbecsdk; print('Import successful')"

# Find example code location
python -c "import pyorbbecsdk; import os; print(os.path.dirname(pyorbbecsdk.__file__))"

2.1.4.7. 1.7 退出虚拟环境

deactivate

2.1.5. 2. 使用 pyenv（管理多个 Python 版本）

pyenv 可在系统中安装和管理多个 Python 版本，适合需要切换不同 Python 版本的开发者。

2.1.5.1. 2.1 安装 pyenv

macOS（使用 Homebrew）：

brew install pyenv

Linux:

curl https://pyenv.run | bash

# Add to shell configuration (~/.bashrc or ~/.zshrc)
echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.bashrc
echo '[[ -d $PYENV_ROOT/bin ]] && export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.bashrc
echo 'eval "$(pyenv init -)"' >> ~/.bashrc

# Reload configuration
source ~/.bashrc

验证安装：

pyenv --version

2.1.5.2. 2.2 安装 Python 3.10

# View installable versions
pyenv install --list | grep "^  3.10"

# Install Python 3.10.16 (example)
pyenv install 3.10.16

# Set global default version (optional)
pyenv global 3.10.16

2.1.5.3. 2.3 在项目目录中设置本地 Python 版本

cd your_project_directory
pyenv local 3.10.16

这会创建一个 .python-version 文件，进入目录时会自动切换 Python 版本。

2.1.5.4. 2.4 创建并激活虚拟环境

# Create venv using pyenv's Python
python3 -m venv orbbec_env

# Activate
source orbbec_env/bin/activate

2.1.5.5. 2.5 安装 pyorbbecsdk2

pip install --upgrade "pyorbbecsdk2[examples]"

2.1.5.6. 2.6 完整流程示例

# Enter project directory
cd ~/projects/orbbec_demo

# Python automatically switches to 3.10.16 (via .python-version)
python --version  # Python 3.10.16

# Activate virtual environment
source orbbec_env/bin/activate

# Run program
python your_script.py

# Exit
deactivate

2.1.6. 3. 使用 conda（适合数据科学用户）

conda 是 Anaconda/Miniconda 的包管理工具，尤其擅长处理非 Python 依赖。

2.1.6.1. 3.1 安装 Miniconda

下载安装程序：

  • Linux:

    wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh

  • macOS (Apple Silicon):

    wget https://repo.anaconda.com/miniconda/Miniconda3-latest-MacOSX-arm64.sh
bash Miniconda3-latest-MacOSX-arm64.sh

  • Windows：下载并运行 Miniconda3-latest-Windows-x86_64.exe

2.1.6.2. 3.2 创建 conda 环境

# Create Python 3.10 environment
conda create -n orbbec python=3.10

# Activate environment
conda activate orbbec

2.1.6.3. 3.3 安装依赖（可选）

如果项目需要其他 conda 软件包：

conda install numpy opencv

2.1.6.4. 3.4 安装 pyorbbecsdk2

pip install --upgrade "pyorbbecsdk2[examples]"

注意：即使使用 conda，也必须通过 pip 安装 pyorbbecsdk2，因为 conda 仓库中没有此包。

2.1.6.5. 3.5 退出环境

conda deactivate

2.1.6.6. 3.6 删除环境（如有需要）

conda remove -n orbbec --all

2.1.7. 各平台注意事项

2.1.7.1. Linux

2.1.7.1.1. Ubuntu/Debian

使用虚拟环境前，可能需要安装 python3-venv：

sudo apt-get update
sudo apt-get install python3-venv

2.1.7.2. macOS

2.1.7.2.1. Xcode 命令行工具

创建虚拟环境前请确保已安装这些工具：

xcode-select --install

2.1.7.2.2. 权限问题

即使使用虚拟环境，访问相机仍需要 sudo：

# Correct
sudo -E python your_script.py

# Incorrect - may lack sufficient permissions
python your_script.py

2.1.7.3. Windows

2.1.7.3.1. Visual C++ Redistributable

确保已安装 Visual C++ Redistributable（通常已预装）。

2.1.7.3.2. PowerShell 执行策略

如果激活虚拟环境时出现执行策略错误：

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

2.1.8. 问题排查

2.1.8.1. ❌ “externally-managed-environment”错误

现象：

error: externally-managed-environment
× This environment is externally managed
╰─> To install Python packages system-wide, try apt install ...

解决方法：使用虚拟环境！

python3 -m venv myenv
source myenv/bin/activate
pip install --upgrade "pyorbbecsdk2[examples]"

2.1.8.2. ❌ “No module named 'venv'”（缺少 venv 模块）

现象：

Error: No module named 'venv'

解决方法：安装 venv 模块

Ubuntu/Debian:

sudo apt-get install python3-venv

CentOS/RHEL:

sudo yum install python3-devel

2.1.8.3. ❌ 虚拟环境已激活，但仍在使用系统 Python

现象：which python 仍显示 /usr/bin/python

解决方法：检查 activate 脚本是否执行成功，或使用完整路径：

source ./orbbec_env/bin/activate
which python  # Should show .../orbbec_env/bin/python

2.1.8.4. ❌ pip install 显示权限不足

现象：

PermissionError: [Errno 13] Permission denied: '.../site-packages/...'

解决方法：确保已激活虚拟环境，且不要使用 sudo：

# Incorrect - do not use sudo inside virtual environment
sudo pip install --upgrade "pyorbbecsdk2[examples]"

# Correct - install directly in virtual environment
pip install --upgrade "pyorbbecsdk2[examples]"

2.1.8.5. ❌ “pyorbbec_env/bin/activate: No such file”（文件不存在）

现象：激活命令失败

解决方法：

  • 检查是否位于正确目录

  • 检查虚拟环境是否创建成功：ls -la orbbec_env/bin/

  • Windows 用户应检查路径分隔符和脚本扩展名是否正确

2.1.9. 📝 最佳实践

  1. 每个项目一个环境：为每个 pyorbbecsdk 项目创建独立虚拟环境

  2. 不要提交环境目录：将虚拟环境目录添加到 .gitignore：

    orbbec_env/
venv/
.venv/
__pycache__/

  3. 记录依赖：使用 pip freeze > requirements.txt 记录依赖

  4. 记录激活步骤：在 README 中包含环境激活说明
