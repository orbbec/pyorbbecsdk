python examples/beginner/01_hello_camera.py

3.4.2. 步骤 2：工作原理

快速入门使用以下核心 API 调用：

📚 API 参考：完整 API 详情请参见 API 文档

from pyorbbecsdk import Pipeline

# 1. Create and start pipeline (zero-config)
pipeline = Pipeline()
pipeline.start()  # Auto-loads default config from XML

# 2. Get synchronized frames
frames = pipeline.wait_for_frames(1000)  # timeout in ms
color = frames.get_color_frame()
depth = frames.get_depth_frame()

# 3. Convert frames for display
color_image = frame_to_bgr_image(color)  # RGB → BGR
depth_mm = depth_data.astype(float32) * depth.get_depth_scale()

# 4. Stop pipeline
pipeline.stop()

关键概念：

  • Pipeline()：管理相机数据流，并自动加载默认设置

  • wait_for_frames()：返回同步的彩色与深度帧

  • frame_to_bgr_image()：将相机输出的图像转换为 OpenCV 兼容的 BGR 格式

  • get_depth_scale()：将原始深度值转换为毫米

3.4.3. 步骤 3：常用自定义配置

3.4.3.1. 自定义分辨率/帧率

from pyorbbecsdk import Config, OBSensorType, OBFormat

config = Config()
profiles = pipeline.get_stream_profile_list(OBSensorType.COLOR_SENSOR)
color_profile = profiles.get_video_stream_profile(1280, 720, OBFormat.RGB, 30)
config.enable_stream(color_profile)
pipeline.start(config)  # Use custom config instead of defaults

3.4.3.2. 仅彩色模式

from pyorbbecsdk import Config, OBSensorType

config = Config()
color_profiles = pipeline.get_stream_profile_list(OBSensorType.COLOR_SENSOR)
color_profile = color_profiles.get_default_video_stream_profile()
config.enable_stream(color_profile)
pipeline.start(config)

3.4.3.3. 将帧保存到磁盘

import cv2
from datetime import datetime

# Inside your capture loop
if color_frame and depth_frame:
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")

    # Save color image
    color_image = frame_to_bgr_image(color_frame)
    cv2.imwrite(f"color_{timestamp}.png", color_image)

    # Save depth as 16-bit PNG
    depth_data = np.frombuffer(depth_frame.get_data(), dtype=np.uint16)
    depth_data = depth_data.reshape((depth_frame.get_height(), depth_frame.get_width()))
    cv2.imwrite(f"depth_{timestamp}.png", depth_data)

3.5. 🐛 问题排查

3.5.1. “No device found”（Linux：未找到设备）

问题：无法检测到相机或权限不足。

解决方法：安装 udev 规则：

# Option 1: From repository
python scripts/env_setup/setup_env.py

# Option 2: From installed package (v2.1.0+)
# 1. Get pyorbbecsdk installation path
python -c "import pyorbbecsdk, os; print(os.path.dirname(pyorbbecsdk.__file__))"
# Example output: /path/to/site-packages/pyorbbecsdk
# 2. Run setup.py(replace with the path from step 1)
python /path/to/site-packages/pyorbbecsdk/shared/setup_env.py

注意：没有 udev 规则时，每次运行脚本都需要 sudo。

快速测试：运行相机入门示例：

python examples/beginner/01_hello_camera.py

3.5.2. Permission denied（macOS：权限不足）

问题：出现 Permission denied 或 Library not loaded 错误。

解决方法：使用 sudo -E 保留环境变量：

sudo -E python hello_camera.py

-E 选项会保留 Python 环境（虚拟环境等）。

3.5.3. 导入错误

问题：ModuleNotFoundError: No module named 'pyorbbecsdk'

解决方法：

# Install the SDK and dependencies
pip install --upgrade "pyorbbecsdk2[examples]"

# Verify installation
python -c "from importlib.metadata import version; print(version('pyorbbecsdk2'))"

3.5.4. 空帧

问题：frames 始终为 None，或帧中没有数据。

解决方法：

  1. 检查超时：将 wait_for_frames() 的超时时间设为建议值 1000 毫秒：

    frames = pipeline.wait_for_frames(1000)  # Wait up to 1000 ms

  2. 确认数据流可用：运行相机入门示例，检查支持的数据流：

    python examples/beginner/01_hello_camera.py

  3. 尝试快速入门：零配置方式会自动处理默认设置：

    python examples/quick_start.py

3.5.5. 显示问题

问题：OpenCV 窗口不显示或图像为空白。

解决方法：

  1. 检查 OpenCV 是否已安装：

    python -c "import cv2; print(cv2.__version__)"

  2. 显示前确保帧有效：

    if color_frame is not None:
    color_image = frame_to_bgr_image(color_frame)
    if color_image is not None:
        cv2.imshow("Color", color_image)

3.5.6. 元数据/时间戳问题（Windows）

问题：时间戳异常或帧同步失败。

解决方法：为每个设备运行一次元数据注册脚本：

# Open PowerShell as Administrator
cd C:\path\to\pyorbbecsdk\scripts\env_setup
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.\obsensor_metadata_win10.ps1 -op install_all

详情请参见注册脚本。

3.7. 💡 使用建议

  1. 从简单开始：先运行 examples/quick_start.py，验证相机正常工作

  2. 按顺序学习：从 examples/beginner/01_hello_camera.py 开始，依次学习 01→09

  3. 检查支持情况：并非所有相机型号都支持所有功能，请查看级别 2 示例中的说明

  4. 使用 Try/Except：将流配置代码放入 try/except 语句中，处理配置过程中可能出现的异常

  5. 始终清理资源：退出前调用 pipeline.stop() 和 cv2.destroyAllWindows()

  6. 注意平台差异：macOS 可能需要 sudo -E，Linux 可能需要 udev 规则

  7. 虚拟环境：使用 venv 或 conda 避免软件包冲突

  8. 优先零配置：先使用 pipeline.start()，再添加手动配置
