# 第三方库

此目录包含 OrbbecSDK 使用的第三方库。

此目录包含以下库：

| 库             | 说明                                                                   | 许可证       | 链接                                              |
| -------------- | ----------------------------------------------------------------------------- | ------------ | ------------------------------------------------- |
| libusb         | 用于访问 USB 设备的跨平台库                                | LGPL-2.1     | <https://github.com/libusb/libusb>                |
| libuvc         | 用于访问 USB 视频设备的跨平台库                          | BSD          | <https://github.com/ktossell/libuvc>              |
| spdlog v1.14.1 | 高性能 C++ 日志库                                                    | MIT          | <https://github.com/gabime/spdlog>                |
| dylib v2.2.1   | 跨平台共享库加载器                                        | MIT          | <https://github.com/martin-olivier/dylib>         |
| libjpeg-turbo v2.0   | JPEG 图像编解码库         | BSD-3-Clause | <https://github.com/libjpeg-turbo/libjpeg-turbo>  |
| libyuv         | 提供 YUV 缩放与转换功能的开源项目 | BSD-3-Clause | <https://chromium.googlesource.com/libyuv/libyuv> |
| live555        | 网络流媒体库                                | LGPL         | <http://www.live555.com/>                           |
| tinyxml2       | 简单、小巧、高效的 C++ XML 解析器                                    | Zlib         | <https://github.com/leethomason/tinyxml2>           |
| cmrc           | 以单个 CMake 脚本实现的资源编译器                                  | MIT          | <https://github.com/vector-of-bool/cmrc>          |
| josncpp        | 用于处理 JSON 的 C++ 库                                      | MIT          | <https://github.com/open-source-parsers/jsoncpp>   |
| mdns-1.4.3     | 用于 mDNS 和 DNS-DS 的跨平台 C 库                                | FREE         | https://github.com/mjansson/mdns                  |
| googletest v1.15.2 | C++ 测试与模拟框架                                      | BSD-3-Clause | <https://github.com/google/googletest>            |
